Saved - Bağlantı Yöneticisi

file:/// doğrudan dosya protokolü algılandı

Neden Beyaz Ekran Gördünüz?
Modern web tarayıcıları (Firefox, Chrome), güvenlik standartları (CORS ve Same-Origin Politikası) gereği file:/// doğrudan dosya açılışlarında JavaScript ES modüllerinin ve IndexedDB veritabanının çalışmasını engeller.

Nasıl Açılır? (2 Kolay Yol):

1. Yol: Tek Tıkla Başlatıcı (Önerilen)

Klasördeki baslat.sh dosyasına çift tıklayın veya terminalde çalıştırın:

./baslat.sh
2. Yol: Terminalden Başlatma

Proje klasöründe terminal açıp şu komutu verin:

npm run dev

Tarayıcınızda otomatik olarak http://localhost:5173 açılacaktır.
